Send from code

One call with a template name and its variables. The response returns an id you can find in the delivery log.

send.js
const res = await courier.send({
  to: "dev@acme.io",
  template: "welcome-v3",
  vars: { name: "Ada", ts: "2026/11/10 14:02" }
});
console.log("sent", res.id);
