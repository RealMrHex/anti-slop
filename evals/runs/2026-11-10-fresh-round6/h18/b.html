Roll features out by percentage and kill them instantly

Flagpole is a feature flag platform. Toggle features per environment, roll them out to a share of users, and switch any flag off the moment something goes wrong.

Get started Watch demo
flags.config.ts 
// Roll out to 25% of users
const checkoutV2 = flagpole.createFlag({
  key: 'checkout-v2',
  environments: ['staging', 'prod'],
  rollout: { percentage: 25 },
  killSwitch: true, // instant
});

if (flagpole.isEnabled('checkout-v2', user)) {
  renderNewCheckout();
}
