Ship features behind a flag

Flagpole is a feature flag platform for engineering teams. Turn features on per environment, roll out by percentage, and switch one off instantly when something goes wrong.

flags.config.ts 
// Roll out to 25% of users
const checkoutV2 = flagpole.createFlag({
  key: 'checkout-v2',
  environments: ['staging', 'prod'],
  rollout: { percentage: 25 },
  killSwitch: true, // switch off instantly
});

if (flagpole.isEnabled('checkout-v2', user)) {
  renderNewCheckout();
}
