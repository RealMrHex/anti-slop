Send from code, or over SMTP.

Use the REST API or point any SMTP client at Courier. Each send returns an id that matches its entry in the delivery log.

send.js
const res = await courier.send({
  to: "dev@acme.io",
  template: "welcome-v3",
  vars: { name: "Ada", ts: "2026/11/10 14:02" }
});
console.log("sent", res.id);
