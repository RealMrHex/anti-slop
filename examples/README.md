# Examples

Worked examples of the output shape for each workflow. They are illustrations
written by hand against the fixtures in [`evals/fixtures/`](../evals/README.md),
not recorded agent runs and not benchmark results.

| File | Shows |
|---|---|
| [audit-report.md](audit-report.md) | An audit with real defects, protected patterns, and source-only honesty |
| [refine-targeted.md](refine-targeted.md) | A tune-mode refine that fixes structure and leaves the look, content, behaviour, and accessibility intact |
| [no-op.md](no-op.md) | A refine request where the right answer is to change nothing |
| [create-briefs.md](create-briefs.md) | Three direction briefs that diverge because the products differ |
