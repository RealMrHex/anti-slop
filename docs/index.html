How it works

Three things you can ask for

The skill is a set of instructions and references your agent reads. It adds no tools, servers, or dependencies.

/anti-slop create

Build something new

Starts from the product and who uses it, then decides a direction before writing code.

  • Real content, every state, phone and desktop
  • Accessibility built in from the first line
  • Looks at the result and corrects it
/anti-slop create a settings page for notification preferences
/anti-slop refine

Improve what exists

Checks the page works, then reworks spacing, colour, type, wording, and motion.

  • Keeps behaviour, real content, and your brand
  • Removes claims it cannot verify, and lists them
  • Tells you what it changed and why
/anti-slop refine src/components/PricingTable.tsx
/anti-slop audit

Review only

Reports what it finds and changes nothing.

  • Each finding has a location and severity
  • Says how sure it is, and on what evidence
  • Notes what already works, so it stays
/anti-slop audit app/dashboard

What matters, in this order

The skill never trades a higher item for a lower one, and it does not stop at the fourth.

  1. It worksFunction, content, and logic stay intact.
  2. Everyone can use itLabels, contrast, focus, keyboard.
  3. The main thing is obviousThe most important information is the most prominent.
  4. It is consistentWith itself and with the system the project already has.
  5. It looks good and fits the productAppealing, finished, and specific to what it is.

Does it work?

    
Tested blind, reported honestly

    
Every test in the repository had one person pick the better of two results without knowing which was which. The results that went badly are published alongside the ones that went well.

    

      
26 of 40screens where the current refine workflow was preferred over the skill it was tested against.

      
10 of 12new screens where an early version was preferred over the same model with no skill.

      
19 runsrecorded, including the ones the skill lost. Nothing was left out.

    

    
These are one judge's preferences on a small model, with one run per side, so read them as a signal and not as proof. On a strong model with a detailed prompt, an earlier version did no better than using no skill. Read every run.

  






  

    
Questions

    
Before you install
Something else? Open an issue on GitHub.

    

      
Which agents does it work with?
Any agent that supports the open Agent Skills format. It has been checked with Claude Code, where /anti-slop works as a slash command. Other clients should load it as a standard skill but have not been tested one by one; where slash commands are not available, ask in words: "use anti-slop to audit this page".

      
Does it install anything or call any service?
No. It is Markdown your agent reads. There is no code to run, no server, no API key, and no telemetry. This page also runs entirely in your browser.

      
Will it force one look on everything?
It has a default standard for small details, such as type weights, spacing, and one accent colour. The identity comes from your product each time, and your project's own design system always wins. Use the playground to set the direction yourself.

      
Will it rewrite my copy or break my page?
It is told not to. Behaviour, real content, brand, and accessibility features are kept. It cleans interface wording such as exclamation marks and greeting titles, removes claims it cannot verify, and lists everything it changed so you can undo any of it.

      
Can it see the page?
Only if your agent can. The skill tells the agent to render and look at the result when it has a browser or screenshot tool, and to say so plainly when it worked from source alone.

      
What is the licence?
MIT. The refine workflow includes a third-party method under CC BY 4.0, kept in its own folder with its notice; the repository's licence section has the details.
